# golden-stack

This is a Bankstack workspace generated by `create-bankstack`: a pnpm-only Nx monorepo with an Astro marketing app, a SvelteKit dashboard, a Hono API, and shared packages for UI, Supabase boundaries, and validation.

Read the [Bankstack docs](https://bankstack.dev/docs/) for the alpha CLI, generated workspace shape, and Cloudflare plus Supabase boundary notes.

If you selected provider AI tooling guidance during generation, read [AI_TOOLS.md](AI_TOOLS.md). The file is documentation only; `create-bankstack` does not run MCP installers or create provider credentials.

## Requirements

- Node.js >=22.12.0
- pnpm 10.33.2

## Commands

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
pnpm test
```

The generated workspace is local-first. It does not require Cloudflare or Supabase credentials to install, check, build, or render the starter apps. Credentials are required only when you wire real deployment, authentication, and data access.

## Apps

- `apps/marketing`: Astro marketing surface.
- `apps/dashboard`: SvelteKit dashboard shell with a local API health call path.
- `apps/api`: Hono API with `/health` and a protected-route stub.

The dashboard can render without Cloudflare or Supabase credentials. If the Hono API is not running locally, the dashboard health proxy returns a local fallback response.

The starter marketing and dashboard surfaces include a visible `Built with Bankstack` attribution link to `https://bankstack.dev/` with `rel="nofollow noopener noreferrer"`. Keep, restyle, or remove it as part of your product branding.

## Packages

- `packages/ui`: shared Tailwind v4 theme CSS and tiny UI primitives/class-name helpers.
- `packages/supabase`: shared Supabase env contracts, client helper, and auth/RLS boundary notes.
- `packages/shared-utils`: shared constants and Zod validation helpers used by apps.

## Local Development

Run all apps together:

```bash
pnpm dev
```

Run one app:

```bash
pnpm --filter @golden-stack/marketing dev
pnpm --filter @golden-stack/dashboard dev
pnpm --filter @golden-stack/api dev
```

The default local ports are:

- Marketing: `http://127.0.0.1:4321`
- Dashboard: `http://127.0.0.1:5173`
- API: `http://127.0.0.1:8787`

## Cloudflare

Cloudflare examples live in:

- `apps/dashboard/wrangler.jsonc`
- `apps/api/wrangler.jsonc`

The dashboard example includes an `API` service binding that points at the generated Hono API Worker. These files are examples only; `create-bankstack` does not create Cloudflare resources, log you in with Wrangler, or deploy anything automatically.

## Supabase

Supabase examples live in:

- `.env.example`
- `apps/dashboard/.env.example`
- `apps/api/.env.example`
- `packages/supabase`
- `supabase/`

The scaffold uses publishable-key terminology for browser-safe configuration and keeps secret/JWT verification concerns on the server side. It does not create product tables or a full auth UI. Before exposing real tables, add migrations and enable row level security policies.

## What Is Not Included Yet

- No Python compute layer in v0.1.
- No generated product database schema.
- No production Cloudflare or Supabase provisioning.
- No full Supabase Auth UI flow.

See [SETUP.md](SETUP.md) for the local-first setup notes and external service boundaries.
